How to use

What This Viewer Does

It opens replay JSON generated by AIMS Replay Viewer and lets you inspect every accepted or rejected Hospital-domain action frame by frame.

Loading Replays

The latest generated replay loads automatically. You can also choose a JSON file with Load replay JSON or drag a replay file onto the drop zone.

Navigation

Use Play, the step buttons, the slider, or the step number field. Drag the board to pan, use the mouse wheel to zoom, hover an agent to inspect intent details, and use the reset control in the lower-right corner to restore the board view.

Debugging Tools

Track an object with values like agent0 or boxA, highlight coordinates with row,column, hover an agent for detailed intent/action fields, pin one agent from the lower-right Agent menu, use Lock View to follow it, adjust interface and log text with the px control, and open Highlights for high-signal current-step events.
