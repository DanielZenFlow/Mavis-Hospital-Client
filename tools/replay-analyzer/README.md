# Replay Analyzer

Offline diagnostic helper for replay JSON files generated by the client.

Example:

```powershell
python tools/replay-analyzer/replay_analyzer.py target/diagnostics/replays/ISO__2026-05-09T20-36-59__partial__5206-steps.json --agent 8 --box L --until 562
```

It reports repeated full states, repeated box edges, action counts, and selected
agent/box trajectories. Use this when a replay shows oscillation but the owning
planner subgoal is not yet obvious from logs.
